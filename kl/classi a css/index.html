Práce s classami a id jak fungují a kde a k čemu se používají

  • id slouží k úravě unikatního prvku
  • class slouží k úpravě stejným způsobem více opakujícíchse prvků
  • index.html je vždy název první stránky jelikož se při více souborů i potom řadí jako první
  • style.css je jedno jak pojmenuji
  • ".cerny" místo "<.p>" mohu použít classi, ty mohu pojmenovat jakkoli a začínají tečkou (.text) jako označení že jde o classu
  • když ale pisu název classi tak bez zečky
